## 所谓的变量提升，是指在JavaScript代码执行过程中， JavaScript引擎（Chrome V8引擎）把变量的声明部分和函数的声明部分提升到代码开头的“行为”。变量提升后，会给变量设置默认值，这个默认值就是我们熟悉的undefined。

模拟变量提升
函数和变量在执行之前都是提升到了代码开头

## JS代码的执行流程
“变量提升”意味着变量和函数的声明会在**物理层面**移动到代码的最前面。
并不准确，·实际上变量和函数声明在代码的位置是不会改变的，而且是在编译阶段被JS引擎放入内存中。

JS代码在执行之前需要被JS 引擎编译，编译完成后，才会进入执行阶段。

## 编译阶段 

词法环境的变量没有提升， 在声明之前词法环境中的变量处于暂时性死区中， 不能使用。
如果在声明前使用， 会报错。

输入一段代码， 经过编译后，会生成两部分内容：
执行上下文（Execution Context）和可执行代码。
执行上下文是JS 执行一段代码的运行环境
调用一个函数，就会进入这个函数的上下文，找到
上下文里的变量环境、词法环境....
